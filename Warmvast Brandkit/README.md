# Warmvast Brandkit

This folder contains the production-ready Warmvast brand assets, organized by use case.

## Folder Map

- `01-logo-assets/` - Master logo files by layout: stacked, horizontal, and icon-only.
- `02-brand-guidelines/` - Brand rules, color specs, typography notes, and usage guidance.
- `03-fonts/` - Brand font files and font packages.
- `04-web-assets/` - Web-specific exports such as favicons and app icons.

## Logo Usage

- Use `vector-source/` files for design, print, and new exports.
- Use `png/` files for quick digital placement.
- Use `color` logos on light backgrounds.
- Use `white` logos on dark or high-contrast backgrounds.

## Favicon Source

Use `01-logo-assets/icon-only/png/warmvast-logo-icon-only-color.png` as the source artwork when generating favicon and app icon sizes.
